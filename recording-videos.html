Recording Videos

Documentation videos are short walkthroughs of [COMPANY] processes that capture desktop and client screen actions. This article covers best practices for recording these videos, how to use the video template, and how to record in Camtasia. If you have not already written a script, see Writing Scripts. You will need a Camtasia license and Windows OS to complete these steps.

Recording Best Practices

Prior to recording:

  • Make sure you are in the [Account Name] account.
  • Set up your data and practice going through the actions and screens that will appear in the video. This will help you with timing and improve load times when recording.
  • Set the screen capture dimensions to match the dimensions of the program you are filming. You may need to film your full screen to show traveling to a specific URL - select Screen 1 or Fullscreen instead of Region to do this.
  • Keep your screens clear of any windows besides your script, Camtasia, and the [COMPANY] application.
  • Silence notifications.

You can record documentation videos directly from Camtasia. Start with downloading the Camtasia Demo Template and follow the instructions below.

Using the Template

Instruction Screenshot
1. Open your downloads folder and right click the zipped template folder. It will likely be named OneDrive_[today’s date].
2. Select Extract All.
3. Select Browse and go to OS (C:) > Users > [your username] and select the Documents folder. Note: if you save active Camtasia files to your OneDrive instead of the C drive, it can cause file syncing issues. It is recommended to only move Camtasia files to cloud storage when they are no longer being edited. You will need to upload your Camtasia files to our SharePoint when your video is finished.
4. Select Select Folder.
5. Select Extract.
6. Open Camtasia and select Open Project.
7. Open Camtasia Demo Template Folder > Camtasia Demo Template > Demo Template.cmproj and select project.
8. Select Open.

Recording in Camtasia

Instruction Screenshot
1. Create a new project using this template by selecting File > Save As… and entering the name of your video. Make sure you are in the folder OS (C:) > Users > [your username] > Documents, not the template folder, and select Save.
2. Select OK on the Camtasia project saved popup message and select Record.
3. Move the Recorder toolbar to a different screen from the screen you want to record and adjust the capture box if necessary.
4. On the Recorder toolbar, make sure Capture Window (the first setting) dimensions are set to capture everything you need to record and Microphone is turned on. USB Camera and System Audio should be turned off.
5. Select Start and begin following the actions in your script while reading the script aloud. Note: You will record a voiceover later, so you do not need to read the script perfectly while screen recording. For now, focus on timing the actions on screen and cleanly moving the cursor. If it is easier, you can abandon reading the script altogether and simply adjust the video timing during editing, although this takes some practice to get right. If you make a mistake and want to start over, select the Reset symbol on the Recorder toolbar. When you have reached the end of the script, select Stop or press F10 on your keyboard.
6. The Camtasia Rev menu will pop up. Select Edit in Camtasia.
7. Your recorded video will now appear on the Camtasia timeline. Select OK on the Camtasia created proxy media message and select File > Save to save your recording.

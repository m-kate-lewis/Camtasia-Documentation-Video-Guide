Editing Videos

Your video needs to look professional, and to do that, you’ll need to edit it. For documentation videos, editing should focus on making your recordings and the correct template elements align properly on the timeline and on the screen.

Go to:

  • Trimming and Arranging Video Components
  • Adding Mouse Effects and Text
  • Adding Captions
  • Exporting Final Videos

If you have not already recorded a voiceover, see Recording Voiceovers. You will need a Camtasia license and Windows OS to complete these steps.

Trimming and Arranging Video Components

Instruction Screenshot
1. Right-click your recorded video component and select Silence Audio. This silences the audio in your video so it does not interfere with your voiceover audio or with the caption creation tool.
2. Make any final adjustments to the screen and audio recordings to sync the actions on screen with the narration audio and remove or replace any misspoken lines.
  • If you need to remove a section of a component, drag the playhead to the start of the section to remove and press the "s" key or select the split button above the timeline. This will split the video at the playhead. Do the same at the end point of the section you want to remove. Then delete the removed section, and close the gap in the recording by dragging the section to the right back to touch the end of the section on the left. Alternately, you can use the Ripple Delete feature, but that will delete everything in that section of the timeline across all tracks.
  • If you need to add time to part of the video, place the playhead over the frame you want to stay on screen longer, right-click and select Extend Frame. Enter a number of seconds to add to the time this frame stays on screen and select Ok. Note: If you have another component immediately after the component you are editing on the timeline, you need to move that component down the timeline to give the edited component room to extend the frame.
3. Align the voiceover and video components to both start after the Title and Subtitle elements end by dragging them along the timeline.
4. Select the video component and:
  1. Set the Scale to 80%. This makes a small portion of the backgrorund around the video recording visible.
  2. Set the x position to 0. This centers the video horizontally.
  3. Set the y position to 50. This gives added space beneath the video recording for captions.
5. Align the background, end logo, and outro components with the end of the video component, so that the end logo and outro components begin at the end of the video component.

Adding Mouse Effects and Text

Instruction Screenshot
1. Select Cursor Effects and drag effects from the panel onto the video component. Recommended effects (Left Click tab):
  1. Sound
  2. Scaling
Note: You may need to lower the Volume on the Click Sound. Compare effect volume to voiceover volume and adjust accordingly.
2. Select the title component and replace the placeholder title with your video title.
3. Select the subtitle component and replace the placeholder subtitle with your video subtitle.
4. Right-click the logo placeholder and select Update Media. Select the logo image file for the software you are documenting from your file folders, then select Open. Note: You may need to resize the logo once it has been updated.
4. Select the outro component and replace the placeholder text with your own.

Adding Captions

Instruction Screenshot
1. Select the Dynamic Caption Styles tab under Captions and drag the first style block onto your voiceover component. A new Dynamic Captions component will appear on the track above the voiceover. Adjust its length to match the length of your audio component. Note: This is an AI feature. You can alternately upload your own captions manually.
2. Select the Dynamic Caption component on the video timeline.
3. Go to the letter tab on the Properties window to update the style of the Dynamic Captions:
  1. Set the Font to a readable font. I chose Calibri.
  2. Set the Size to 42.
  3. Adjust the text box size to fit one line at a time, centered on the lowest 4th of the screen.
4. Select the voiceover component while the Dynamic Caption Styles window is open to edit the captions. You will likely need to correct certain spellings here or fill in missed words from the auto-generation process.

Exporting Final Videos

Instruction Screenshot
1. Select Export and then select Local file…
2. On the main Export Local File window and Dimensions tab, confirm:
  1. The File name is accurate
  2. The File type is MP4
  3. The Save location is in the correct location on your computer.
  4. The Dimensions are 1080p
3. On the Encoding tab, confirm:
  1. The Frame rate is 30
  2. The Quality is 75%
4. Select Export.
5. Select Open File Location.
6. Open the new video file and review your video.

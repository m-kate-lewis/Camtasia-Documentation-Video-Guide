Editing Videos

Your video needs to look professional, and to do that, you’ll need to edit it. For documentation videos, editing should focus on making your recordings and the correct template elements align properly on the timeline and on the screen.

Go to:

  • Trimming and Arranging Video Components
  • Adding Mouse Effects and Text
  • Adding Captions
  • Exporting Final Video

If you have not already recorded a voiceover, see Recording Voiceovers. You will need a Camtasia license and Windows OS to complete these steps.

Trimming and Arranging Video Components

Instruction Screenshot
1. Right-click your recorded video component and select Separate Audio and Video. Delete the separated audio track. This removes the audio from your video so it does not interfere with your voiceover audio or with the caption creation tool.
2. Make any final adjustments to the screen recording to sync the actions on screen with the narration audio. If you need to remove part of the video, drag it to the right on the timeline so that there are no other components in the same frame. Then use the green and red timeline selectors to highlight the portion of the video you want to remove, right-click and select Ripple Delete. If you need to add time to part of the video, place the playhead over the frame you want to stay on screen longer, right-click and select Extend Frame. Enter a number of seconds to add to the time this frame stays on screen and select Ok. Note: If you have another component immediately after the component you are editing on the timeline, you need to move that component down the timeline to give the edited component room to extend the frame.
3. Select the voiceover component and the video component and drag them back along the timeline towards the beginning of the video.
4. Select the video component and:
  1. Set the Scale to 80%. This makes a small portion of the backgrorund around the video recording visible.
  2. Set the x position to 0. This centers the video horizontally.
  3. Set the y position to 50. This gives added space beneath the video recording for captions.
  4. Drag the component back on the timeline so that it begins immediately after the intro screen.
5. Drag the voiceover component up to an empty track, placing it so that it starts at the same time as the video component, and trim the following components:
  1. Drag the outro component back or forward until its start lines up with the end of the video component.
  2. Trim (or extend) the length of the background loop to end when the outro ends.

Adding Mouse Effects and Text

Instruction Screenshot
1. Select Cursor Effects and drag effects from the panel onto the video component. Recommended effects (Left Click tab):
  1. Sound
  2. Scaling
Note: You may need to lower the Volume on the Click Sound. Compare effect volume to voiceover volume and adjust accordingly.
2. Select the title component and replace the placeholder title with your video title.
3. Select the subtitle component and replace the placeholder subtitle with your video subtitle.

Adding Captions

Instruction Screenshot
1. Select the Dynamic Caption Styles tab under Captions and drag the first style block onto your voiceover component. A new Dynamic Captions component will appear on the track above the voiceover.
2. Select the Dynamic Caption component on the video timeline.
3. Update the style of the Dynamic Captions:
  1. Set the Font to Lato.
  2. Set the Size to 42.
  3. Adjust the text box size to fit one line at a time, centered on the lowest 4th of the screen.
4. Select the voiceover component while the Dynamic Caption Styles window is open to edit the captions. You will likely need to correct certain spellings here or fill in missed words from the auto-generation process.

Exporting Final Videos

Instruction Screenshot
1. Select Export and then select Local file…
2. Confirm:
  1. The File name is accurate
  2. The File type is MP4
  3. The Save location is in your video folder on your OneDrive
  4. The Dimensions are 1080p
3. Confirm:
  1. The Frame rate is 30
  2. The Quality is 75%
4. Select Export.
5. Select Open File Location.
6. Open the new video file and review your video.

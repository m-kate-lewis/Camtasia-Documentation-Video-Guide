Writing Scripts

Documentation videos show users the simplest way to complete a common process in a piece of software. This article outlines the style, scope, and pacing you should use when writing scripts for these videos. It also includes an example script to use as a template.

Guidelines

Prioritize clarity, brevity, and maintaining a casual tone. Sentences should flow naturally when read aloud. As with written documentation, state the names of buttons, menus, fields, and other UI elements exactly as they appear.

The scope of a video should be small and specific, and it must relate to a specific software feature or setting without going into troubleshooting or work-arounds. Identify a single, simple process—or a single, complex step in a larger process—to walkthrough from beginning to end. Add context and caveats when necessary, but do not go into every possible option or special use case. Stick to the “Happy Path.”

Consider pacing as well. Think about how long you would naturally remain on each screen of the walkthrough. You want to add relevant information to the screen you are actively looking at when you are looking at it, but where you can, try to put more of your narration on screens that have more actions. When read aloud, the script should not exceed three minutes of narration, and two minutes should generally be the goal.

Template

Download an empty template and read through the example below. This example explains how to convert an ebook from one format to another using the open source ebook software Calibre.

Topic: How to convert books in Calibre

Scene Narration Visuals
Intro Hello. In this video I’m going to show you how to convert an e-book to a different format using the open source software Calibre. You may need to convert your e-books to different formats in order to read them on different devices. If you have not already downloaded and installed Calibre, do so now. These instructions are based on the 9.14 version of Calibre for Windows. Video Title – Empty desktop
1 First, I need to open Calibre. Once the program is running, I can select the book I want to convert. If I select multiple books, I can convert those books in bulk, but only if they are being converted to the same format. For this example, I will select just one book: Wolf Worm by T. Kingfisher. Open Calibre and select Wolf Worm, by T. Kingfisher.
2 Next, I will select the Convert books button on the top menu. A new popup window opens, displaying the book cover and settings options for the conversion. For most books, you won't need to adjust many of these settings. You may wish to go to the Look & feel tab to customize fonts, styling, and layout for your converted book. Select Convert books, navigate to the Look & feel tab, then return to the Metadata tab.
3 The most important settings are the Input and Output formats. In the top left corner of the window, you'll see the Input format, which is the current format of your e-book. In the top right, you can select the Output format for your book. Under Output format, I am going to select PDF. Select Output format dropdown, then select PDF.
4 Now that I've selected my output format, I can start the conversion. I will select Ok on the conversion window, and the window will disappear. Select Ok.
5 In the bottom right corner of the screen, you should see a Jobs field that displays active jobs, including conversions. This field will display the number 1 until our conversion is complete. None.
6 The Jobs field is now displaying 0. If I look at my e-book in this main library window, I can see that the book is in both the original input format, EPUB, and our selected output format, PDF. Select Wolf Worm, by T. Kingfisher.
Outro With that, I have successfully converted my e-book. For more information on how to use specific Calibre features, see the Calibre User Manual. Add Calibre branding.

About this Guide

This guide demonstrates how to use Camtasia to create software documentation videos. Neither I nor this guide are affiliated with Camtasia or TechSmith in any way; it is merely a tool. You can translate this guide for use with other video editing tools if you like. Additionally, you will find instructional content in this guide based on my own style recommendations and preferences. This guide is not intended for use as documentation for Camtasia. Please see TechSmith's documentation resources instead.

Example Video: Converting Books in Calibre

This is an example of the kind of documentation video this guide can help you create. It explains a simple feature you can use in Calibre, an open source software for managing e-books. The video was created in coordination with this guide, and you will see examples throughout referencing it.

Licenses and Versions

This guide is based on the free desktop application of Camtasia for Windows, version 2026.2.0. Its instructions may not apply to other versions and licenses of Camtasia.
